# Getting help

Before reporting a problem, read the notes for the installed release and check existing issues.

Include the exact application version, Windows version, affected GT edition, expected behavior, actual behavior and reproducible steps. For display issues, include GPU model and monitor resolution. State whether the issue reproduces with the documented defaults.

Do not post passwords, tokens, private databases, original game files, saved progress or raw support archives publicly. Redact personal paths and account details from screenshots and logs. A private support archive should be shared only through a separately agreed channel.

Feature requests can describe the intended result and why it would help. An issue submission does not imply that an edition or hardware configuration is supported.
