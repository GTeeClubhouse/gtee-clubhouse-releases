# Third-party notices

Beta 1.0 includes third-party runtime components under their respective licenses. No blanket license is assigned here to third-party software or game content.

The [Beta 1.0 release](https://github.com/natemac/gtee-clubhouse-releases/releases/tag/v1.0.0-beta.1) supplies **GTee-Clubhouse-Beta-1.0-Corresponding-Sources.zip** alongside the installer. It contains the modified BoxedWine native-host sources, build records, bounded filename-sanitization tooling, official MAME 0.289 source archive, and packaged decoder/compatibility sources and notices. Its member manifest records file hashes. It does not contain the private application repository or game files.

Notices remain with their installed components. The installation's `App/GTee-Clubhouse/notices` directory contains the exact bundled .NET runtime-pack licenses and a source-download index. Other notices accompany MAME, Python, SDL, zlib, PostgreSQL, decoder/compatibility libraries and the MEGA upload implementation.

Upstream references: [BoxedWine](https://github.com/danoon2/Boxedwine), [MAME 0.289](https://github.com/mamedev/mame/releases/tag/mame0289), [.NET](https://github.com/dotnet/runtime), [Python](https://www.python.org/), [SDL](https://libsdl.org/), [PostgreSQL](https://www.postgresql.org/) and [MEGA SDK](https://github.com/meganz/sdk).
